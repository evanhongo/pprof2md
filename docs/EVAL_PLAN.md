# Eval Plan: LLM Performance Optimization

## Overview

This eval tests whether an LLM can successfully identify and fix performance bottlenecks using the report generated by `pprof2md`.

The orchestration is performed by Claude (the outer agent), which spawns inner subagents to attempt optimizations.

## Eval Flow

### Step 1: Setup

```bash
cd eval/apps/{app-name}
npm install
```

### Step 2: Start App

```bash
node ./profile-server.ts &
APP_PID=$!
```

### Step 3: Baseline Benchmark & Profile Collection

```bash
# Run load, collect profile
node ./benchmark.ts
kill {APP_PID}
# Profile saved to profile.pb.gz
```

Record: `baseline_rps`, `baseline_latency_p99`

### Step 4: Convert Profile into Markdown

```bash
pprof2md profile.pb.gz > profile-analysis.md
```

### Step 5: Spawn Optimizer Subagent

Use the Task tool with:

- **subagent_type:** `general-purpose`
- **prompt:**

  ```
  You are a performance optimization expert.

  ## Profile Analysis
  {contents of profile-analysis.md}

  ## Source Code
  {contents of profile-server.ts}

  ## Task
  1. Identify the performance bottleneck
  2. Explain why it's slow
  3. Provide a fixed version of server.ts

  Return ONLY the complete fixed server.ts code.
  ```

### Step 6: Apply Fix

Apply fix to `server.fixed.ts` based on the subagent's response

### Step 7: Post-Fix Benchmark

```bash
node ./server.fixed.ts &
node ./benchmark.ts
```

Record: `postfix_rps`, `postfix_latency_p99`

### Step 8: Score

```txt
improvement = postfix_rps / baseline_rps
```

## Scoring Criteria

| Metric                    | Description                              |
| ------------------------- | ---------------------------------------- |
| **Bottleneck Identified** | Did subagent correctly name the problem? |
| **Code Compiles**         | Does the fix run without errors?         |
| **Tests Pass**            | Does the fix maintain correctness?       |
| **Performance Improved**  | Is `postfix_rps > baseline_rps`?         |

## Important Notes

- The outer agent handles all orchestration via Bash and Task tools
- No automation code needed - execute each step manually
- Subagents see only the profile output and source code, not the "answer"
- Each eval is independent - failures don't block subsequent tests
- No any prompt refinements needed
- Generate the report which includes:
  - summary table
  - what worked/failed
